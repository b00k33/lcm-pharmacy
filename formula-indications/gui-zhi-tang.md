# Gui Zhi Tang · Bing (disease) indications

Source: her table, pasted 2026-10-05. Each row is a clinical area, with the Gui Zhi Tang clues that point to it. Bing ticks add points toward this formula.

| Clinical area | Examples | Typical Gui Zhi Tang clues |
|---|---|---|
| Acute febrile illness | Colds, viral-type febrile illnesses, recurrent fever | Feverishness + spontaneous sweating + aversion to wind/cold |
| Chronic / recurrent fever | Low-grade or unexplained recurrent fever | Fever with the characteristic exterior-deficiency presentation |
| Abnormal sweating | Spontaneous sweating, excessive sweating, night sweating | Easy sweating + sensitivity to wind/cold |
| Autonomic dysfunction | Autonomic instability, functional autonomic symptoms | Sweating + palpitations + dizziness + sensitivity/reactivity |
| Palpitations | Functional palpitations, some tachycardic presentations | Palpitations + sweating + insomnia/vivid dreams + appropriate pulse |
| Cardiovascular inflammatory presentations | Some myocarditis-type or vascular inflammatory presentations | Must have the Gui Zhi Tang pattern rather than simply the diagnosis |
| Headache | Exterior-type headache | Headache + sweating + wind sensitivity |
| Musculoskeletal pain | Body aches, joint pain, muscle tension/spasm | Pain with exterior-deficiency signs |
| Neck/upper-back stiffness | Stiffness associated with an exterior presentation | Gui Zhi presentation ± need for modification |
| Abdominal pain | Certain functional abdominal pain presentations | Abdominal discomfort with the Gui Zhi pattern |
| Diarrhea | Certain deficiency/exterior-associated diarrheal presentations | Diarrhea with the appropriate Gui Zhi-family pattern |
| Dermatological disorders | Eczema, urticaria, erythema, psoriasis | Skin disorder + sweating/wind sensitivity + floating/lax pulse |
| Allergic rhinitis | Recurrent allergic nasal symptoms | Gui Zhi presentation, often requiring modification |
| Asthma / allergic respiratory symptoms | Some asthma presentations | Gui Zhi pattern + appropriate respiratory signs |
| Pregnancy-related nausea | Morning sickness | Nausea/dry heaving with the characteristic associated pattern |
| Sleep disturbance | Insomnia, vivid/dream-filled sleep | Especially when associated with palpitations, sweating and sensitivity |
| Dizziness | Certain functional dizziness presentations | Dizziness + sweating + appropriate pulse/pattern |
| Flushing / episodic heat sensation | Functional flushing-type presentations | Particularly when alternating with cold sensitivity/sweating |

## Rules to keep with this formula
- **Cardiovascular inflammatory presentations:** the Gui Zhi Tang pattern must be present. The diagnosis alone is not enough.
- **Neck/upper-back stiffness, Allergic rhinitis, Asthma:** "±/often needs modification". Gui Zhi Tang fits, but the plan may need a modified version.

## Contraindications: a diagnosis alone never means Gui Zhi Tang
- **Eczema** ≠ automatically Gui Zhi Tang.
- **Palpitations** ≠ automatically Gui Zhi Tang.
- **Fever** ≠ automatically Gui Zhi Tang.
- **Asthma** ≠ automatically Gui Zhi Tang.

Each of these needs the Gui Zhi Tang pattern (the clues above) before the formula is suggested.

## Contraindicated signs: do not suggest Gui Zhi Tang when these are present
- Interior excess
- Strong, forceful pulse
- High-intensity interior heat
- Marked thirst
- Irritability/agitation
- Red tongue with yellow coating
- A strong exterior-excess pattern with no sweating
