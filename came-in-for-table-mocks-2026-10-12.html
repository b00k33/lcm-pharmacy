Option C · Quiet table with an estimated start date (your pick)

How long and Started are two columns of the same table. Pick how long and the start date works itself out (~); type an exact date and how long follows.

First visit · Acute — while unwell
What it does
  • Started is its own column. A date worked out from how long shows as ~12 Sep; a date you typed shows plain, 12 Sep. Same idea as the estimated dates on IVF.
  • Tap either value to open the quick picks (1 wk … 5 yr) and an exact-date box. A quick pick gives an estimate, the date box gives an exact start and how long follows from it.
  • Years only appear when the date is not this year (~Oct 2021).
  • Suggested chips copy the main complaint's how long and start date. Plan tag stays as a small tag under the main complaint.
  • This start date is what the Goal line and the treatment table's "for 4 wk" read, exactly as How long does today.
